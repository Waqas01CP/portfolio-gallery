# AGENTS.md

This file routes an AI coding agent to what it should read. It states no
rule of its own.

portfolio-gallery is a portfolio-site template anyone can copy and publish
with GitHub Pages, and a gallery of designs for it, followed by a showcase
of contributors' own sites.

## Who you may be helping

**A visitor**: someone who wants to make their own site from the template,
contribute a design, add their site to the showcase, report a problem,
ask for a showcase entry's removal, ask a question or report a security
problem. Read [README.md](README.md). Its table,
[What do you want to do?](README.md#what-do-you-want-to-do), says where
each path starts. Its prompt for an AI assistant, under
[Ask an AI assistant to guide you](README.md#ask-an-ai-assistant-to-guide-you),
holds every path in full, with its steps, its rules and what the checks
and the review look for. Follow that prompt as if the person had given it
to you. A contributor adding a design or their own site is a visitor.

**The maintainer, working on the project itself**: its engine, checks,
workflows, documents or records. Read [CLAUDE.md](CLAUDE.md) and follow
it, whatever tool you run in: it is the project's working rules, and its
reading order continues with [STATE.md](STATE.md).

If you cannot tell which, ask the person.

Claude Code reads CLAUDE.md by itself, and not this file while CLAUDE.md
exists; this file is for every other coding agent.
